
# Multi-Tape Turing Machine Compiler & Simulator

Desktop-приложение на **C++** и **wxWidgets** для компиляции и симуляции **многоленточной машины Тьюринга** с визуализацией лент, пошаговым выполнением и редактированием переходов через GUI.

## Features

- GUI-приложение на **wxWidgets**
- компиляция программы машины Тьюринга из текстового описания
- симуляция **multi-tape Turing machine**
- пошаговый и автоматический запуск
- визуализация содержимого лент и положения головок
- управление числом лент
- загрузка и сохранение программ в файл
- ручное добавление и удаление переходов через таблицу
- готовые шаблоны программ для тестирования
- собственные структуры данных для работы с лентой и последовательностями

## Project idea

Проект реализует учебный симулятор многоленточной машины Тьюринга с удобным графическим интерфейсом.  
Пользователь может:

- задать программу в текстовом формате;
- скомпилировать её в набор переходов;
- загрузить входные данные на ленты;
- запускать выполнение по шагам или автоматически;
- наблюдать за изменением состояния машины и содержимого лент в реальном времени.

Такой проект полезен для изучения:

- теории вычислимости;
- принципов работы машины Тьюринга;
- проектирования GUI-приложений на C++;
- реализации структур данных и симуляторов.

## Architecture

### `main.cpp`
Точка входа в приложение.  
Создаёт `wxApp` и открывает главное окно симулятора.

### `MainFrame.h`
Главное окно приложения. Содержит:

- вкладку с программой машины Тьюринга;
- вкладку симуляции;
- вкладку управления переходами;
- таймер для автоматического выполнения;
- визуализацию лент;
- элементы управления скоростью, шагами и состоянием машины.

### `Compiler.h`
Компилятор текстового описания машины Тьюринга.  
Разбирает строки с переходами и преобразует их в структуру переходов для симулятора.

### `BidirectionalLazyTape.h`
Реализация двусторонней ленивой ленты.

Особенности:
- поддержка отрицательных и положительных индексов;
- ленивое создание ячеек;
- хранение только реально использованных элементов;
- удобна для моделирования потенциально бесконечной ленты.

### `DynamicArray.h`
Собственная реализация динамического массива с поддержкой:
- resize;
- append;
- copy / move semantics;
- контроля capacity.

### `exceptions.h`
Набор пользовательских исключений для обработки ошибок симулятора и контейнеров.

### `identifier.h`
Идентификаторы GUI-событий: кнопки, таймер, загрузка/сохранение, таблица переходов, шаблоны и другие элементы интерфейса.

## Program format

Одна команда задаётся в формате:

```text
FromState,Read1,Read2,Read3->ToState,Write1,Write2,Write3,Move1,Move2,Move3
````

Где:

* `FromState` — текущее состояние
* `Read1..Read3` — символы, считываемые с лент
* `ToState` — следующее состояние
* `Write1..Write3` — символы, записываемые на ленты
* `Move1..Move3` — движение головок:

  * `R` — right
  * `L` — left
  * `S` — stay

Пустой символ задаётся пробелом.

### Example

```text
q0,0, , ->q0,0,0, ,R,R,S
q0,1, , ->q0,1,1, ,R,R,S
q0, , , ->q1, , , ,S,S,S
```

## Templates

В проекте предусмотрены готовые шаблоны, например:

* copy `a-z`

* unary addition

Это делает приложение удобным для демонстрации и тестирования без ручного ввода программы с нуля.
